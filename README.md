# Portfolio Website Starter Code

**Overview**
This project is a multi-page personal portfolio website created using HTML and CSS. The website showcases my skills, projects, background, and provides visitors with a way to contact me.

The project began as incomplete starter code that required debugging, restructuring, accessibility improvements, and additional functionality.

Pages
The website contains four pages:
Home – Introduction and overview of the portfolio.
About – Information about me, my journey, skills, and experience.
Projects – Examples of projects I have worked on.
Contact – An accessible contact form for visitors.

**Issues Found**
During my review of the original starter code, I identified several issues, including:
Missing navigation menus.
Incorrect use of generic <div> elements.
Missing image alternative text.
Missing skills table.
Incomplete Projects page.
Missing form labels.
Insufficient form input types.
Missing HTML5 form validation.
Missing navigation styling.
Poor spacing and alignment.
Missing hover and focus states.
Insufficient CSS selector variety.
A more detailed list is available in the design/issues-identified.txt document.

**Fixes Implemented**
The website was improved by:
1. Replacing unnecessary <div> elements with semantic HTML5 elements.
2. Adding consistent navigation to all four pages.
3. Adding descriptive alt text to images.
4. Creating a structured skills table.
5. Completing the Projects page.
6. Improving the Contact form.
7. Adding HTML5 validation.
8. Improving CSS organisation and styling.
9. Adding responsive layouts.
10. Adding hover and focus states.
11. Improving colour contrast and accessibility.

**HTML Structure**
Semantic HTML5 elements are used throughout the website, including:
<header>
<nav>
<main>
<section>
<article>
<footer>
This provides clearer document structure and improves accessibility.

**CSS and Styling**
Different CSS selector types are demonstrated, including:
* Element selectors
* Class selectors
* ID selectors
* Descendant selectors
* Pseudo-classes such as :hover and :focus
* CSS is also used for spacing, borders, typography, responsive layouts, tables, forms and navigation.

**Accessibility**
Accessibility improvements include:
* Descriptive image alternative text.
* Labels associated with form controls.
* Semantic HTML.
* Keyboard focus states.
* Appropriate heading structure.
* Improved colour contrast.
* HTML5 form validation.

**How to View**
1. Clone or download this repository.
2. Open the project folder.
3. Open index.html in a web browser.
4. Use the navigation menu to move between the four pages.
5. No additional software or server is required.

**Reflection**
Debugging the starter website helped me understand the importance of semantic HTML, accessibility, consistent navigation, CSS organisation and testing.
One of the main challenges was identifying how individual HTML and CSS errors affected the overall website. Fixing these issues step by step helped me understand how HTML structure and CSS styling work together to create an accessible and professional website.
